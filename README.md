# Transport Booking System

## 📌 Overview

A Java-based mini project that demonstrates cab and bus booking operations using object-oriented programming concepts.  
This project focuses on basic system design, data handling, and execution flow.

---

## ⚡ Features

- Cab booking functionality  
- Bus booking functionality  
- Basic booking logic and flow  
- Modular structure using OOP principles  

---

## 🛠️ Tech Stack

- Java (OOP concepts)  

---

transport-booking-system/
